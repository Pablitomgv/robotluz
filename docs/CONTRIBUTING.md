# Contribuir a Robotluz

¡Gracias por querer aportar! Robotluz se construye entre todos.

## Formas de contribuir

- 🐛 **Reportar bugs**: abrí un [issue](https://github.com/Pablitomgv/robotluz/issues) describiendo el problema y cómo reproducirlo.
- 💡 **Sugerir ideas**: abrí un issue con la etiqueta `idea`.
- 🌎 **Traducir**: ayudá con nuevos idiomas o mejorá los existentes.
- 🎨 **Arte**: sprites SVG, íconos, paletas accesibles.
- 🎵 **Música y sonidos**: pistas CC0 o composiciones originales.
- 🎮 **Diseñar niveles**: proponé niveles nuevos con progresión pedagógica clara.
- 📝 **Documentación**: corregí errores, mejorá explicaciones, agregá ejemplos.
- 💻 **Código**: ver sección "Cómo enviar un cambio".
